# The Last Umbrella · 最後一把傘

Eight-second visual milestone for a rewindable observation puzzle in a Taipei arcade. One customer approaches the stand, winds a gold strap twice around a dark umbrella and lowers it into the tray. Play, pause, scrub, inspect the hands, and drag or use the arrow keys to change perspective. English and Traditional Chinese.

The browser renderer and ECS are Estella v0.103.0. The scene and character are original procedural geometry. Build on Linux with Node, npm, curl and unzip using `bash tools/build.sh`. Serve dist over HTTP. The preview workflow exports a static site and captures desktop and phone-sized frames under the project subpath. It has no deployment step.

This milestone tests whether the gesture is readable. The eventual forty-second mystery, other customers, and ownership decision are outside this preview.
